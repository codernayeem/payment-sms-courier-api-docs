Step 3: Refund Payment
Refund URL: https://gateway.sbrecurring.pay.bka.sh/gateway/api/subscription/payment/refund
Request:
curl --location --
request POST 'https://gateway.sbrecurring.pay.bka.sh/gateway/api/subscription/payme
nt/refund' \
--header 'version: v1.0' \
--header 'channelId: Merchant WEB' \
--header 'timeStamp: 2021-08-18T08:29:56.436364Z' \
--header 'x-api-key: YOUR_APP_KEY' \
--header 'Content-Type: application/json' \
--data-raw '{
 "paymentId": "1232",
 "amount": "10"
}'
Response:
For Refund API, Merchant will only receive HTTP Status as OK. And after that, merchant will get the Webhook
for Refund (success/fail)
